# <非公式> azooKey Custom Keyboard Editor

azooKey のカスタムキーボード（Custard）JSONを、ブラウザ上で視覚的に編集するための**非公式ツール**です。

> このプロジェクトは azooKey 公式とは関係のない第三者製ツールです。

## できること

- Custard JSONの読み込み・編集・保存
- `grid_fit` / `grid_scroll` の編集
- キーの追加・削除・移動・複数選択
- フリック方向ごとのラベル・アクション編集
- アクション詳細編集
- JSON直接編集
- 表示倍率変更
- ショートカットのカスタマイズ
- ブラウザ内での元に戻す / やり直し
- 起動時にサンプルの `japanese_flick` キーボードを表示

## プライバシー

読み込んだJSONは**ブラウザ内だけで処理**されます。

このバージョンには、読み込んだJSONを外部サーバーへ送信する機能はありません。

ショートカットや一部の表示設定は、ブラウザの `localStorage` に保存されます。

## 使い方

1. 公開ページを開く
2. 「開く」からCustard JSONを選択
3. 画面上で編集
4. 「名前を付けて保存」または「上書き」で保存

重要なJSONを編集する場合は、事前にバックアップを取ることをおすすめします。

## ブラウザについて

基本的な編集機能はブラウザ上で動作します。

ブラウザが File System Access API に対応している場合は、選択したファイルへ直接上書きできます。
未対応ブラウザでは、保存時にJSONファイルをダウンロードする方式になります。

## 対応状況

このツールは azooKey のCustard JSONを扱うための非公式エディタです。

azooKey本体のすべてのバージョン・すべてのCustard仕様との完全な互換性を保証するものではありません。
保存前に警告表示やJSON内容を確認してください。
